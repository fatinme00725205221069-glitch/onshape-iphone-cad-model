# iPhone 18 Pro Concept | 3D CAD Model

### Designed in Onshape | Parametric Modeling & Product Design

## 📌 Project Overview

This repository showcases my 3D CAD model of an iPhone 18 Pro concept, designed using Onshape.

The project was an opportunity to explore product modeling and practice creating detailed 3D geometry using sketches, extrusions, and feature-based CAD tools.

My focus was on developing the phone's overall shape, exterior details, camera arrangement, buttons, and other visible features while improving my understanding of parametric modeling.

## 🛠️ Tools & Software

- **CAD Software:** Onshape
- **Modeling Method:** Feature-Based Parametric Modeling
- **Project Type:** Consumer Product CAD Design
- **Design:** iPhone 18 Pro Concept (Unofficial)

## ⚙️ Design Highlights

- Rounded rectangular smartphone body with defined edges
- Front display with a dark screen finish
- Rear camera arrangement with raised camera elements
- Side buttons and exterior frame details
- Top and bottom profiles
- Bottom charging-port and speaker-grille details
- 3D visualization from multiple orientations
